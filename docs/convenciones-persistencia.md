# Convenciones de persistencia (JPA / PostgreSQL)

> **Responsable:** Integrante 3 — *define* la convención; cada integrante mantiene sus propias entidades.
> **Alcance:** aplica a todos los microservicios del monorepo.
> **Estado:** refleja lo implementado en `develop` (servicios integrados de I1/I3/I4).

## 1. Stack

- **Java 21** + **Spring Boot 4.1.1** + Spring Data JPA (Hibernate) + **Flyway** + **PostgreSQL** (RDS en cloud, contenedor en local).
- Nota: `restaurantes-service` y `productos-service` (I2) están en Spring Boot 3.5.6; su alineación se trata en el issue #27.

## 2. Configuración por servicio

- Cada microservicio usa **`application.yml`** (no `.properties`).
- Cada servicio usa **esquema propio** de PostgreSQL y **base de datos local dedicada**.
- Cada servicio incluye su propio **`compose.yml`** (PostgreSQL local) y **`.env.example`**.

Fragmento de referencia:

```yaml
spring:
  config:
    import: optional:file:.env.local[.properties]
  datasource:
    url: ${DB_URL:jdbc:postgresql://localhost:<puerto>/pedidos360_<servicio>}
    username: ${DB_USERNAME:pedidos360_<servicio>}
    password: ${DB_PASSWORD:}
  jpa:
    open-in-view: false
    hibernate:
      ddl-auto: validate
    properties:
      hibernate:
        default_schema: <servicio>
        jdbc:
          time_zone: UTC
  flyway:
    default-schema: <servicio>
    schemas: <servicio>
    clean-disabled: true
```

## 3. Nombres de tablas y columnas

- Tablas en `snake_case` y **plural**: `pedidos`, `lineas_pedido`, `pagos`, `restaurantes`, `productos`.
- Columnas en `snake_case`, **en español** (coherente con lo implementado): `usuario_id`, `creado_en`, `actualizado_en`, `precio_unitario`.
- Relaciones `N:M` → tabla de unión explícita y nombrada.

## 4. Claves primarias

- Default: `BIGINT GENERATED BY DEFAULT AS IDENTITY` / `Long` → `@GeneratedValue(strategy = GenerationType.IDENTITY)`.
- Columna PK siempre `id`.
- `UUID` solo cuando la entidad se expone externamente (ver `usuarios.entra_object_id`).

## 5. Columnas de auditoría

- `creado_en`, `actualizado_en` → `Instant` (UTC), columna `timestamptz` en PostgreSQL.
- Se completan con `@PrePersist` / `@PreUpdate` en la entidad.
- Control de concurrencia optimista: columna `version` + `@Version`.

## 6. Enums

- `@Enumerated(EnumType.STRING)` (valores legibles y estables; evitar `ordinal`).
- Columna con el nombre del enum (ej. `estado`), con `CHECK` de valores permitidos en la migración cuando aplique.

## 7. Montos y moneda

- Montos en **entero** (`Long`), sin decimales flotantes. **No usar `double`.**
- Guardar la columna de moneda por entidad (ej. `moneda`, ISO-4217 como `CLP`).
- *Pendiente de acordar:* si la unidad es valor entero o céntimos (el catálogo publica `precio: 6990` como entero).

## 8. Fechas / horas

- `Instant` en la entidad → columna `timestamptz` (UTC), `hibernate.jdbc.time_zone: UTC`. Serializar como ISO-8601.

## 9. Migraciones (Flyway)

- Ruta: `src/main/resources/db/migration/`.
- Nombres: `V<version>__<descripcion>.sql` (ej. `V1__crear_pedidos.sql`), versiones incrementales.
- **Nunca editar** una migración ya aplicada; crear una nueva.

## 10. Variables de conexión

Variables de entorno (nunca en el repo):

```

DB_USERNAME=pedidos360_<servicio>
```

## 12. Buenas prácticas JPA

- No exponer entidades como DTO de contrato; mapear a DTO.
- Transacciones en la capa de servicio (`@Transactional`).
- Controlar *lazy loading* dentro del servicio; evitar N+1; usar DTO agregado.
- `open-in-view: false` obligatorio.
- `ddl-auto: validate`: Hibernate valida el modelo, no crea ni modifica tablas.

## 13. Ejemplo reutilizable (esqueleto)

```java
@Entity
@Table(name = "pedidos", schema = "pedidos")
public class Pedido {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(name = "usuario_id", nullable = false)
    private Long usuarioId;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false, length = 20)
    private EstadoPedido estado;

    @Column(nullable = false)
    private Long total;

    @Column(nullable = false, length = 3)
    private String moneda;

    @Column(name = "creado_en", nullable = false, updatable = false)
    private Instant creadoEn;

    @Column(name = "actualizado_en", nullable = false)
    private Instant actualizadoEn;

    @Version
    @Column(nullable = false)
    private Long version;

    // constructor, getters y reglas de negocio
}
```

> Esqueleto basado en `pedidos-service`; los detalles se ajustan al implementar cada servicio.
